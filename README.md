# lazyBot
A low-noise AI companion that sends one meaningful message daily to keep you focused on becoming who you promised yourself to be.
## Why lazyBot?
Most productivity systems fail because they become noise.
lazyBot is designed differently:

* **low-noise**
* **emotionally aware**
* **identity-driven**
* **deeply personal**

Sometimes one meaningful notification is more powerful than 100 reminders.
---

A low-noise AI accountability bot that sends deeply personalized Telegram messages throughout the day.

Instead of productivity spam, dashboards, or endless distractions, lazyBot delivers emotionally intelligent messages based on:
* goals
* ambitions
* emotional state
* struggles
* discipline
* current life situation

The goal is simple:
> protect focus, reinforce identity, and stay consistent.

—
⚡ Features
* AI-generated personalized motivation
* Telegram phone notifications
* Multiple scheduled notifications
* GitHub Actions automation
* OpenAI integration
* Personalized emotional context
* Zero server needed
* Fully cloud automated

---

## 🛠 Tech Stack
* **Python**
* **OpenAI API**
* **Telegram Bot API**
* **GitHub Actions**
* **Cron Scheduling**

---

## ⚙️ How It Works

```text
GitHub Actions Scheduler
        ↓
Runs Python Script
        ↓
OpenAI generates message
        ↓
Telegram Bot API
        ↓
Phone notification arrives
```
